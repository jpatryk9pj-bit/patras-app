# PATRAS — wersja z edycją ćwiczeń i dziennikiem wyników

## Uruchomienie
Otwórz `index.html` w przeglądarce. Na GitHub Pages opublikuj zawartość folderu repozytorium tak jak dotychczas.

## Nowe funkcje
- Edycja i dodawanie ćwiczeń w wybranym dniu planu.
- Zmiana nazwy, liczby serii, zakresu powtórzeń/czasu/dystansu, przerw i wskazówek.
- Przycisk **Wynik** przy każdym ćwiczeniu.
- Rejestrowanie rzeczywistego obciążenia i powtórzeń/czasu dla każdej serii.
- Opcjonalny zapis RPE i notatki z wykonania.
- Historia zapisów danego ćwiczenia i możliwość ponownego otwarcia wcześniejszego wpisu do edycji.
- Dane treningowe zapisują się lokalnie w przeglądarce w `localStorage` pod kluczem `patras_app_v2`.

## Ważne
Dane są przechowywane na danym urządzeniu i w danej przeglądarce. Wyczyścić dane witryny = można utracić zapisy. Ta wersja nie zapewnia jeszcze synchronizacji między urządzeniami ani automatycznej kopii w chmurze.
